# MIRA

MIRA is a developmental AI project.

## North Star

Build MIRA into a persistent, low-latency, egocentric AI that develops through lived experience, memory, repetition, correction, association, and plasticity.

MIRA should not be scripted into appearing developed. She should develop.

Everything in this repository serves that goal. Models, memory stores, LoRAs, context managers, sensors, body architecture, tests, and infrastructure are means—not the project itself.
